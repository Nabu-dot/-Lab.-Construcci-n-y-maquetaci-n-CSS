Laboratorio: Maquetación Web Semántica

La maquetación web es el proceso de organizar y distribuir los elementos de una página (textos, imágenes, menús) para que tengan un orden visual claro. Se hace combinando HTML, que da la estructura, con CSS, que da el diseño.

Una buena maquetación mejora la legibilidad y permite que el sitio se adapte a distintos dispositivos, desde un computador hasta un celular. Herramientas como Flexbox facilitan crear columnas flexibles.

Recursos de Interés

HTML: es el lenguaje de marcado que define la estructura y el contenido de una página web.

CSS: es el lenguaje de estilos que controla colores, tipografías y la distribución de los elementos.
